# MedScribe Lite - AI Medical Scribe

**Live MVP:** https://harmonious-unicorn-d2f00a.netlify.app/
**Team:** Diva (FGIET)

### Current MVP (Hackathon Submission)
- HTML, Tailwind, Vanilla JS
- Web Speech API for Hindi/Bhojpuri
- Netlify Hosted - 100% Working

### Proposed Architecture (Phase 2)
- Frontend: React PWA
- Backend: This Flask API
- AI: Whisper On-Device + Bhashini + GPT-4
- DB: Firebase Firestore (Encrypted)

### API Endpoints
- `POST /api/transcribe` - Voice to Text
- `POST /api/generate-prescription` - AI Prescription

Built for rural doctors in UP where 1 doctor = 1456 patients.
